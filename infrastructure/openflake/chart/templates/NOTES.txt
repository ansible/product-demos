OpenFlake {{ .Chart.AppVersion }} is installing into namespace {{ .Release.Namespace }}.

Watch it come up:

  oc rollout status deploy/{{ include "openflake.backend.fullname" . }} -n {{ .Release.Namespace }}
  oc rollout status deploy/{{ include "openflake.frontend.fullname" . }} -n {{ .Release.Namespace }}

The backend applies Alembic migrations and seeds reference data during its
first boot, so that rollout can take a couple of minutes.

ACTION REQUIRED -- route.host was not set.

OpenShift generated a hostname for the Route, but the backend could not be
told about it at install time, so BASE_URL and CORS_ORIGINS currently point at
the in-cluster Service. Reference links and browser API clients will be wrong
until you feed the real hostname back in:

  ROUTE_HOST=$(oc get route {{ include "openflake.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.spec.host}')
  helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values --set route.host="$ROUTE_HOST"

The Ansible role in ansible/roles/openflake_openshift does this automatically.
{{- end }}
{{- else -}}

{{- end }}
